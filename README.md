# Práctica de Redes Neuronales Básicas

## Descripción

Práctica introductoria de Deep Learning desarrollada en Python
utilizando NumPy y Google Colab.

## Contenido

- Perceptrón básico
- Red neuronal de una capa
- Red neuronal multicapa tipo Vanilla
- Operaciones matriciales con NumPy
- Vectorización
- Funciones de activación

## Tecnologías utilizadas

- Python
- NumPy
- Google Colab
